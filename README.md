# Calculator

A responsive and interactive calculator built using HTML, CSS, and JavaScript.

This project demonstrates basic arithmetic operations, DOM manipulation, event handling, keyboard support, and responsive web design.

---

## 🔗 Live Demo

👉 [Open Calculator](https://shekharsonawane16.github.io/Calculator)

---

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus operation
- Decimal number support
- Clear button
- Backspace button
- Division-by-zero handling
- Keyboard support
- Responsive design
- Clean and modern user interface
- PWA-ready structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web App Manifest

---

## ⌨️ Keyboard Controls

| Key | Action |
|---|---|
| `0-9` | Enter numbers |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Modulus |
| `Enter` / `=` | Calculate |
| `Backspace` | Delete last digit |
| `Esc` / `C` | Clear |
